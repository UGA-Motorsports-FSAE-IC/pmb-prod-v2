#   pyocd

# --backend gdb talks to a running ST-LINK_gdbserver or OpenOCD over TCP using
# nothing but the standard library, so pyocd is optional if you go that route --
# which is the usual answer on Windows, where pyocd needs a WinUSB-bound driver
# and ST's own driver is not one. See TUNING.md section 15.
#
# No scipy, no matplotlib, no OpenOCD required.
